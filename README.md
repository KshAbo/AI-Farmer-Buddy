# Overview

AI Farmer Buddy is a comprehensive agricultural support platform developed for the Capital One Launchpad Hackathon. This AI-powered dashboard empowers farmers by providing contextual advice, crop health analysis, real-time weather and market updates, and financial calculators in multiple languages.

# Features

1. Conversational Chatbot powered by Google Gemini API

2. AI Crop Scanner (Image diagnosis)

3. Weather Forecast & Alerts

4. Market Intelligence (current mandi prices, 30-day trends)

5. Financial Services (Loan eligibility calculator)

6. Multilingual Support

8. Responsive, single-page dashboard UI
